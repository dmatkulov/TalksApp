Приложение TalksApp написанное по видеоуроку Max Roslow
(https://www.youtube.com/watch?v=GOZrjIpRtkI)

В приложении можно регистрироваться писать пост и комментарии, удалять и ставить лайки а также подписываться на других пользователей Также можно редактировать информацию о себе

**Для запуска приложения (скорпировать локально в одну директорию):**
1. Сервер (Express.js)
2. Клиентская часть (React TS)
3. Открыть обе директории в рекдакторе кода
4. Установить зависимости – npm install
5. Запустить приложение Docker
6. Запустить команду в директории с сервером docker compose up --build
7. В адресной строке открыть URL – http://localhost:8000/
